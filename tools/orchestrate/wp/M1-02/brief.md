# WP M1-02 — index crate (SQLite catalog index)

Read crates/engine-api/CONTRACTS.md first and use its types; do not modify engine-api (if a contract change is unavoidable, stop and print RESULT: FAIL with the reason so it can be reviewed). The workspace root Cargo.toml lists this crate already; add dependencies via [workspace.dependencies] where the version is pinned there. Everything must pass `cargo test -p <crate>` and `cargo clippy -p <crate> --all-targets -- -D warnings` and `cargo fmt --check`. Fixtures: `fixtures/raw/` has one CR3, ARW, NEF, RAF, DNG each (run `bash fixtures/fetch.sh` if missing). Tests that need fixtures must skip with a message when the directory is absent.

Implement `crates/index` per docs/05 §2 (read it) using `rusqlite` bundled with FTS5 (and R*Tree if the feature builds; otherwise a plain lat/lon index and note it):
- `Index::open(path)` with WAL, `synchronous=NORMAL`, mmap; schema migrations table; tables `root`, `folder`, `file`, `image` (one per file, virtual copies later), `metadata` (flattened EXIF/IPTC/XMP key→value), `keyword` + `image_keyword` with closure table for hierarchy, `selection` (decision, grade, mark per image, mirroring engine_api::recipe::Selection), `recipe_hash`, `preview` (content hash → preview state), `fts` (FTS5 over filename, keywords, caption, camera, lens).
- `Scanner`: walk a root folder (walkdir), upsert files by (path, size, mtime), read sidecars if present via a `SidecarReader` trait that this crate defines and `crates/sidecar` will implement later (for now a no-op impl), extract basic metadata via `kamadak-exif` for JPEG/TIFF/DNG and leave raw-only fields for a `MetadataProvider` trait (no-op impl now). Incremental: a second scan of an unchanged tree does zero writes.
- Query API: `search(&Query) -> Vec<ImageId>` where Query has text, folder scope, decision/grade/mark filters, date range, camera/lens, keyword; facets(`&Query`) returns counts per camera/lens/keyword/decision. Paged.
- Benchmark test (ignored by default, run with --ignored): synthesise 100 000 image rows with realistic metadata and assert a text search and a faceted query each complete in < 100 ms after warmup; print timings.
- Unit tests for migrations, incremental scan, closure-table keyword queries, selection round trip.
