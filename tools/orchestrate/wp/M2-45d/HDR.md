## Implemented

- Core optional `ExportSettings::hdr: Option<HdrTransfer>` selects PQ or HLG.
  SDR defaults and existing SDR codecs are unchanged.
- PNG HDR uses 16-bit RGB and a cICP chunk: Rec.2020 primaries, transfer 16/18,
  identity matrix, full range. No contradictory SDR ICC/sRGB chunk.
- AVIF HDR uses 10/12-bit full-range GBR. The AV1 color description and HEIF
  nclx carry Rec.2020 + PQ/HLG. The SDR ICC property is omitted and property
  associations are adjusted correctly. XMP remains an associated metadata item.
- PQ is absolute ST 2084 with diffuse white at 203 cd/m². HLG uses the BT.2100
  1000-nit reference display and system gamma 1.2, including luminance-dependent
  inverse OOTF. Recipe HDR enable/headroom selects the sigmoid ceiling, bounded
  by PQ's 10,000 nits or the HLG reference display's 1000 nits. Disabled HDR or
  zero stops gives 203 nits. Nonfinite/out-of-range headroom is rejected.
- Normalized display-linear RGB is resized/sharpened before transfer encoding.
  Perceptual mapping compresses chroma at constant luminance; clip mode clips.
  HLG's transfer-dependent gamut constraint is reevaluated after filtering.
  The existing cancellation, same-directory temporary files, sync and no-clobber
  publication remain in use. CPU rendering itself remains non-interruptible.
- CLI: `--hdr pq|hlg --color-space rec2020` with PNG `--bit-depth 16` or AVIF
  `--bit-depth 10|12`. Headroom comes from the source recipe, not a second flag.
- FFI/preset JSON: `hdr: "pq"|"hlg"` (default null), with Rec.2020 and matching
  bit depth. Previous/multi-preset paths inherit it through ExportOptions.
- MCP: existing `hdr: true` now supports PNG16/AVIF10/12. New optional
  `hdr_transfer` defaults to PQ, `avif_bit_depth` to 10 in HDR/8 in SDR.
  Schema mirrors include the transfer enum. Invalid combinations are rejected.
- Generated Swift bindings were regenerated by the requested build script;
  no tracked binding diff because the FFI extension remains JSON. No UI changes.
- No new dependencies, licensing exceptions or vendor code.

2. ISO 21496-1 gain-map JPEG, including SDR base/gain-map encoding, standard
