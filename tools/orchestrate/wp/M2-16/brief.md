# WP M2-16 — Photo Merge: HDR (deghost), panorama, HDR panorama (`merge`)

Read docs/01 §2.20, docs/07 §7 "Merges", crates/raw-decode (CfaImage, metadata incl. exposure), crates/pipeline-cpu (demosaic, camera colour), crates/lens (line/feature helpers may be reusable), crates/export (DNG write? — if no DNG writer exists, implement a minimal linear DNG writer here: 16-bit or float, with camera matrix, as-shot neutral, and our recipe as XMP), engine-api.
Implement `crates/merge`:
- **HDR**: align exposures (global translation + small rotation via phase correlation on downsampled luminance, then per-tile refinement), estimate exposure ratios from EXIF and refine from overlapping histograms, merge in linear camera RGB with a weighting function (well-exposedness, clipping aware), deghosting (reference-frame based; per-pixel mask where motion exceeds threshold; strength none/low/med/high), output a linear 32-bit float DNG + our recipe with auto-tone defaults.
- **Panorama**: feature detection/matching (ORB-like: implement FAST + BRIEF or use a permissive crate such as `akaze`/`imageproc` — check licence), robust homography/spherical model estimation with RANSAC, projection modes (spherical, cylindrical, perspective), multi-band (Laplacian pyramid) blending, boundary warp (content-preserving mesh warp to fill edges; a simpler "auto crop + fill by inpainting placeholder" acceptable for now, documented), output DNG.
- **HDR panorama**: HDR per bracket set, then pano.
- Tests: synthetic bracket (one image with simulated exposures ±2 EV and noise) merges to within 2% of the ground truth linear scene; a moving object in one frame is deghosted (mask covers it); synthetic pano from a wide synthetic scene split into three overlapping crops with perspective recovers the scene with PSNR > 30 dB in overlaps; DNG output re-reads through raw-decode with correct dimensions and matrix.
`cargo test -p merge -p raw-decode --release`, clippy -D warnings, fmt. engine-api unchanged (report needed fields).
