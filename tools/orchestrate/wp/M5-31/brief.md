## Round 2 (mandatory before merge; data from Machine B's B5-07)
Measured on M4 Max, 1368×912 viewport: (1) 20 MP documents fail with "style alpha canvas exceeds CPU pixel limit" because render::styles MAX_PIXELS (16.7M) is applied to the full level-0 canvas plus padding even when rendering level 1/2; (2) 16 MP at level 1 takes ~108 s per styled frame because emit_styles recomputes full-canvas effect planes for every tile job. Required, for BOTH the resident path and the CPU reference path:
- Compute style planes per requested level and region with an effect-radius halo (scaled to the level), never at full level 0 for a lower-level request.
- Cache planes per (layer revision, style hash, global light, level, region/tile) so tile jobs share one computation; bounded by the existing memory budget.
- Scope the pixel limit to the region actually computed; 20 MP and 50 MP documents must render at L0/L1/L2.
- No CPU fallback for any common effect on the resident path.
Add tests/benches: 20 MP document with 5 styled layers renders at L1 (1368×912 viewport) under 100 ms resident and under 2 s CPU; 50 MP renders without the pixel-limit error; region/level results match a full-canvas reference crop within the stated tolerance.
