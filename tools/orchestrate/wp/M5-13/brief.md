Build **document mode** in the mac app:
- `ViewMode.document` entered by File ▸ New Document… (size/depth/profile sheet), File ▸ Open Document… (`.tessera-doc`, `.psd`, `.psb`, flat images), Library ▸ Edit in Layers (⌘E, current image, developed), and by opening a document file from Finder. Multiple documents: a document switcher in the toolbar (tabs style from DESIGN.md), dirty dot, ⌘W closes with a save prompt. File ▸ Save / Save As… / Export Flat… (reuse the export sheet's format/colour controls). Edit ▸ Undo/Redo, Layer menu (New ▸ Pixel/Group/Adjustment ▸ … /Fill ▸ …, Duplicate ⌘J, Delete, Group ⌘G, Ungroup ⇧⌘G, Merge Down ⌘E in document mode, Flatten, Layer Mask ▸ Reveal All/Hide All/From Selection/Delete/Disable), Select ▸ All/Deselect/Rect Marquee only for now, View ▸ Zoom In/Out/Fit/100%.
- **Viewport** (`DocumentViewport`, AppKit `NSView` + `CAMetalLayer`, EDR like the loupe): presents the backend's surface, checkerboard under transparency (Swift-drawn), zoom 1:1/fit/⌘+/⌘−/scrubby (⌥-drag)/pinch, space-drag pan, rulers optional, marching-ants overlay for the marquee selection (dashed path animated at 30 fps), transient HUD with zoom percentage. Viewport changes call `setViewport(level, rect, zoom)`; level = floor(log2(1/zoom)) clamped.
- **Layers panel** (SwiftUI over an `NSOutlineView` for the tree, since SwiftUI `List` cannot recycle 500 rows): rows with thumbnail (from `layerThumbnail`), name (double-click rename), eye, kind glyph, mask thumbnail with enable toggle and link chain, clipping indent, lock glyphs; drag to reorder and into/out of groups (multi-select); header row: blend mode popup (27 modes in the Photoshop groups, Pass Through for groups), Opacity and Fill sliders (custom `NSControl` from Basic, interactive drag → `interactive: true`, mouse-up → `commit`), lock buttons, filter row placeholder; footer: add (menu), add mask, add adjustment (menu), group, delete. Context menu mirrors the Layer menu.
- **Properties panel**: for the selected layer: name, kind, bounds; adjustment editors for every `Adjustment` variant in crates/compositor/src/adjust.rs (Levels: per-channel input/output sliders + gamma; Curves: `CurveEditorView` per channel; Hue/Saturation with colourize; Exposure; Posterize; Threshold; Channel Mixer; Invert has no controls) with live drag on the interactive path and commit on release; fill editors (solid colour with `NSColorWell`, gradient stops editor, pattern placeholder); group mode toggle; smart object: transform fields and "Edit Contents" placeholder; text: placeholder note.
- **History panel**: list of history items with the current one highlighted, click = checkout, snapshots section with "New Snapshot" (name sheet) and restore, memory used line.
- Keyboard map in document mode (document in KeyRouter): V move, M marquee, ⌘A/⌘D, ⌘Z/⇧⌘Z, ⌘J, ⌘G/⇧⌘G, ⌘E merge down, ⌘+/−/0/1, space pan, Tab hides panels, F cycles screen modes; culling single-key shortcuts must not fire in document mode.
- Accessibility identifiers on every control (`document.layers.row.<index>`, `document.layers.blendMode`, `document.properties.*`, `document.history.row.<index>`, `document.viewport`), DESIGN.md compliance (no new colours; lint test green), an `ACCEPTANCE.md` section "Document mode" with numbered Sol steps over the stub and over the real engine (both), and Swift tests in TesseraCoreTests for: layer tree flattening/diff (`LayerNode` list → outline model with minimal moves), blend mode table (27 names, stable order, round trip to backend strings), viewport level maths, keyboard routing by mode, and stub backend undo/redo/save.
