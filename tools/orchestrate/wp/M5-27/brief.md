# WP M5-27 — Adaptive Wide Angle and Vanishing Point

Read docs/02 §6 (Adaptive Wide Angle: constraint lines on fisheye/wide; Vanishing Point: perspective planes for clone/paint) and the implementation notes (camera model from lens profile → sphere → reprojection with constraint lines solved as least-squares warp; user-defined perspective planes as homographies), crates/lens (lens profiles, fisheye/rectilinear models, lensfun data), crates/transform (TransformOp, displacement rendering, warp mesh, TRANSFORM.md), crates/brush (clone/heal sampling API in heal.rs / engine.rs).
Deliver in crates/transform (new modules) + a small `crates/lens` addition if a projection helper is missing:
1. **Adaptive Wide Angle**: given a lens model (from crates/lens profile or manual focal/fisheye type), build the sphere mapping; user constraints = line segments marked straight (optionally vertical/horizontal), plus scale/focal/crop factor; solve a smooth warp (least-squares over a control mesh with line-straightness and orientation terms, regularised for smoothness) and emit a `TransformOp::Displacement` renderable by the existing displacement path (CPU + GPU). Tests: a synthetic fisheye-distorted grid with marked lines becomes straight within 0.5 px; determinism; degenerate constraints error clearly.
2. **Vanishing Point**: perspective planes defined by 4 points (with tear-off adjacent planes sharing an edge and angle), each a homography; `PlaneSpace` maps canvas↔plane coordinates; clone/stamp and paste operations expressed in plane space and mapped back with the plane's homography and correct resampling; multi-plane strokes crossing an edge. Provide a `VanishingPoint` document tool payload (serde) and a brush-engine adapter (`brush::api` hooks) so a stroke's source sampling goes through the plane mapping. Tests: paste a checker onto a plane and verify the projected corners; clone across a shared edge continuity; round trip serde.
Document formulas/limits in crates/transform/TRANSFORM.md. Gate: `cargo test -p transform -p lens -p brush --release && cargo clippy -p transform -p lens -p brush --all-targets -- -D warnings && cargo fmt --check`.
