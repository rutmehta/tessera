# WP M2-08 — Masks and local adjustments (engine)

Read docs/01 §2.15 (masking), docs/07 §5 and §7 "Local", crates/engine-api/src/recipe/mask.rs (mask model already in the contract), crates/pipeline-cpu (Locals stage currently a no-op?), crates/image-core (StageOp, graph), crates/pipeline-gpu. Implement in pipeline-cpu (reference) with GPU ports in pipeline-gpu where straightforward:
- Mask rasterisation at any pyramid level: linear gradient, radial gradient (feather, invert), brush strokes (stamp along path with pressure/flow/feather/erase), luminance range and colour range (with smoothness), depth range placeholder (uses a provided depth plane), intersect/subtract/add composition into a mask group; edge-aware refinement (guided filter on the mask) as an option; cached rasters via image-core cache keyed by mask hash + level.
- Local adjustments: per-mask-group the Lightroom local slider set (exposure, contrast, highlights, shadows, whites, blacks, temperature, tint, texture, clarity, dehaze, saturation, sharpness, noise, moiré placeholder, hue shift) applied in the Locals stage by blending the locally adjusted result with the mask weight, in the same working space as the global ops; amount slider per group.
- Tests: rasterised gradients match analytic values; brush stamps accumulate and erase; range masks select the expected pixels on synthetic images; local exposure +1 doubles linear values only inside a full-white mask; goldens unchanged with no masks; GPU vs CPU tolerance per docs/11 §1.3.
`cargo test -p pipeline-cpu -p pipeline-gpu -p image-core --release`, clippy -D warnings, fmt. engine-api unchanged (report if the mask model lacks a field).
