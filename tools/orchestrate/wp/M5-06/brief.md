# WP M5-06 — Filters for the layered editor (`filters`)

Read docs/02 §8 (filters inventory: blur family, sharpen, noise, distort, stylize, render, Camera Raw filter as a special case, Smart Filters non-destructive), §7 (Image > Adjustments as direct ops), crates/engine-api (Tile, Pyramid), crates/pipeline-cpu (guided filter, unsharp, NR implementations to reuse via public functions), crates/pipeline-gpu (WGSL patterns), crates/compositor (tiled raster type: code against `compositor::raster::Raster` via its public API; M5-03/M5-04 are editing compositor concurrently, so put everything in a new `crates/filters` and only depend on published types).
Implement `crates/filters` with a `Filter` trait (`apply(&Raster, &FilterParams, cancel) -> Raster`, plus `halo()` for tiled evaluation and a GPU impl where marked): Gaussian blur (separable, radius up to 250 with downsample-and-upsample for large radii), box, motion, radial (spin/zoom), lens blur (reuse ml-depth's layered blur on a supplied depth/mask), surface blur (bilateral), unsharp mask, smart sharpen (deconvolution-lite: reuse pipeline-cpu), high pass, add noise (gaussian/uniform, mono), reduce noise (reuse NR), median, dust & scratches (median with threshold), pinch/spherize/twirl/wave/ripple (inverse-mapped resampling with Lanczos-3), polar↔rectangular, offset, emboss, find edges, solarize, oil paint placeholder, clouds/difference clouds (Perlin), lens flare placeholder, and "Adjust" direct ops (levels/curves/HSL/brightness-contrast/exposure/vibrance/photo filter/channel mixer/gradient map/selective colour/threshold/posterize/invert/desaturate/black & white/match colour (Oklab statistics transfer, reuse ml colour matching if present)). GPU: blurs, unsharp, high pass, noise, the distort resamplers, and the adjust ops in WGSL gated vs CPU (docs/11 §1.3).
Tests: each filter neutral at identity params; Gaussian matches a scalar reference within 1e-5; separable vs direct; large-radius approximation bound documented and tested; distort inverse maps round-trip on a grid; tiled evaluation with halo equals whole-image; GPU vs CPU tolerance; a bench (ignored) printing ms per filter on a 20 MP raster at L0 and L2.
`cargo test -p filters --release`, clippy -D warnings, fmt. engine-api unchanged. Allowed: Cargo.lock, Cargo.toml, crates/filters/**, tools/orchestrate/wp/M5-06/**.
