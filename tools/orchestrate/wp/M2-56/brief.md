# WP M2-56 — Layout foundations: the shell never overflows the window; shared controls never collide

Evidence: tools/orchestrate/audits/layout/REPORT.md (read it all; screenshot shots/window-document-1280x800-dark.png) and Machine B's on-screen verifier (branch origin/verify/B5-10 if pushed; findings: at 1280–1512 pt the window toolbar draws over the document options bar and the inspector's "Properties" heading, clicks meant for Character ▸ Style hit Auto Edit; after a resize the sidebar slides under the traffic lights; a fresh --app-dir instance lists other instances' folders).
Scope (audit packages L2, L3, L5 plus the shell part of L1/D01–D02; Machine B does the document inspector itself afterwards):
1. **Shell budget and safe area** (`Shell/ContentView.swift`, `App/TesseraApp.swift` window/toolbar setup): the root never places a subtree outside the window (no negative origins); content respects the unified toolbar/title-bar safe area; panels yield width in a defined order (library sidebar collapses first, then inspector width shrinks to its minimum, then the filmstrip hides) instead of the whole split view being centred outside the host; the declared minimum window size equals the real minimum content budget. Add a root-containment assertion usable by tests.
2. **Shared width contracts** (`App/Components.swift`, `App/Theme.swift`, `Inspector/ValueSlider.swift`, `Inspector/LibraryPanels.swift` FlowRow/KeywordChip, `Loupe/SoftProof.swift` menus): remove two-axis `fixedSize()` on text/menu groups, measure instead of counting characters, ValueSlider reserves a label/value gap and truncates the label (value always fully visible), FlowRow measures and places with the same proposal and wraps/truncates oversized chips.
3. **Shell compact behaviour** (L3): status bar groups, toolbar groups and tether/filter rows get compact/overflow variants; no retained invisible slots (hidden views removed, not opacity 0).
4. **Geometry polish** (L5): Compare caption/badge shared partition, colour-wheel/curve/slider handle paint envelopes, sidebar hidden-badge slot.
5. **--app-dir isolation**: the folder registry and any other per-user state live under --app-dir when it is set.
6. **Tests**: a background-safe layout test (never `makeKeyAndOrderFront`; host the real ContentView in an offscreen/prohibited-activation window like the audit's window-probe) at 960×600, 1280×800, 1440×900, 1728×1117 in light and dark for library, raw folder and the stub document: assert root containment (no ancestor frame outside the host), the toolbar/safe-area top inset, and no overlap between actionable AX siblings; unit tests for ValueSlider label/value rects at 80/110 pt widths, FlowRow oversized chip, Compare partition.
