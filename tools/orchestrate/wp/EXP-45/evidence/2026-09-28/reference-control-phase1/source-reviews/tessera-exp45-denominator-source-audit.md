## Pinned codec contract

The public compressed-gain API accepts `uhdr_gainmap_metadata_t` floating-point fields, not a wire-layout/common-denominator switch (`ultrahdr_api.h:345-370`; `examples/ultrahdr_app.cpp:765-767`; `lib/src/ultrahdr_api.cpp:1055-1068`). `gainmapMetadataFloatToFraction` converts each metadata value to a rational (`lib/src/gainmapmetadata.cpp:354-431`), and the continued-fraction helper returns denominator 1 immediately for exact integer values (`lib/src/gainmapmath.cpp:1626-1672`). The current metadata values log2(1)=0, log2(16)=4, gamma=1 and offsets=0 therefore all become denominator 1.

`encodeGainmapMetadata` checks whether the two headroom denominators and every in-use channel denominator equal the base-headroom denominator (`lib/src/gainmapmetadata.cpp:126-161`). If so it sets flag bit `0x08` and writes a single common denominator; otherwise it writes every rational denominator explicitly (`:162-192`). There is no public option in the pinned API or sample app to force the explicit branch while retaining these exact integer rational values. Changing floating-point values to trigger the branch would alter actual metadata semantics. A source fork that forces this internal branch would be a separate diagnostic, not the unmodified independent encoder.

## Exact v0 payload and controlled variant

The retained Google16 auxiliary APP2 is at marker byte 1481, length field bytes 1483-1484 = `0x0043`, ISO namespace starts byte 1485, and version/flags payload starts byte 1513. It has min/writer versions `0/0`, flag `0x48` (base color space `0x40` plus common-denominator `0x08`; one channel, forward direction). The common form contains, in order, BE32 common denominator `1`, base headroom numerator `0`, alternate headroom numerator `4`, then signed min numerator `0`, signed max numerator `4`, unsigned gamma numerator `1`, signed SDR offset numerator `0`, signed HDR offset numerator `0`. The decoder's corresponding flag and field order are at `gainmapmetadata.cpp:224-286`; masks `0x80` multi-channel and `0x40` base-space are in `lib/include/ultrahdr/gainmapmetadata.h:26-27`.

The smallest semantically identical **byte-level control copy** would keep versions `0/0` and base-space bit, clear only the common bit (`0x48 -> 0x40`), and encode the seven values as explicit BE32 numerator/denominator pairs in this order: base headroom `0/1`, alternate headroom `4/1`, gain min `0/1`, gain max `4/1`, gamma `1/1`, SDR offset `0/1`, HDR offset `0/1`. Signed numerator representation applies to gain min/max and both offsets; all listed values are nonnegative. Common form is 37 bytes after the namespace; explicit form is 61, adding 24 bytes. MPF first-entry size `1479` stays unchanged. The whole file grows from 1895 to 1919 bytes.
