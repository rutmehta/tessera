# WP M2-20 — Export dialog, export presets, publish-ready output, and Print (Opus)

Read docs/01 §2.22 (Export), §2.26 (Print: layout, soft proof, sharpening for media), docs/06 §4 (albums → publish later), crates/export (ExportSettings, batch, upscale, ICC, XMP, mask hooks), crates/color-mgmt (proof transforms, printer profiles), crates/tessera-ffi (Engine, sessions; export is not exposed yet), apps/mac (menus, sheets, M2-12/M2-13b patterns, KeyRouter).
1. FFI: `export_batch(image_ids | album | query, ExportSettings JSON, progress callback, cancel)` with per-item results; export presets CRUD (JSON under app-dir/ExportPresets, ship defaults: Web 2048 sRGB q85, Full-size JPEG, 16-bit TIFF ProPhoto, Print 300 dpi long edge); `printer_profiles()` list from ColorSync; `soft_proof(session, profile, intent, simulate_paper)` toggle on the develop session (uses color-mgmt).
2. App: **File ▸ Export…** (⇧⌘E) sheet: preset picker + editable fields (format/quality, colour space, sizing, output sharpening, metadata, naming template with live example, upscale 2×/4×, destination, "after export: open in Finder"), applies to the selection or current album; non-modal progress in the status strip with cancel; results toast with failures listed. **Soft Proofing** toggle in Develop (S) with profile/intent pickers, paper-white simulation, and gamut-warning overlay colours. **File ▸ Print…** sheet: page setup, layout (single, contact sheet grid, custom cells), margins, rotate-to-fit, resolution, print sharpening (matte/glossy), colour handling (app-managed with the printer profile, or printer-managed), print to PDF as a first-class path (`NSPrintOperation` with a custom NSView drawing engine renders), and a "Print to file (JPEG at N dpi)" option.
3. ACCEPTANCE.md section: export 3 raws with the Web preset and verify files/dimensions; print to PDF a contact sheet and verify a PDF exists with the right page count.
Tests: Rust for FFI export + presets; Swift tests for naming templates, preset persistence, layout maths for contact sheets. `cargo test -p tessera-ffi -p export --release`, clippy, fmt, `(cd apps/mac && ./build-ffi.sh && swift build && swift test)`. engine-api unchanged. Do not edit crates/tessera-ffi/src/develop.rs except to add the soft-proof toggle (small, additive) and coordinate by keeping that edit minimal — another package is editing that file.
