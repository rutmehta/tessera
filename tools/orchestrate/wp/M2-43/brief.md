# WP M2-43 — App: allow Develop on rendered files (JPEG/TIFF/PNG/HEIC)

The engine develops rendered files since M2-29 (crates/tessera-ffi develop sessions accept them; see ACCEPTANCE.md section "M2-29. Develop a rendered JPEG in the loupe"). The app still refuses: apps/mac/Sources/Tessera/App/AppModel.swift `openDevelop(for:)` guards `item.kind == .raw` and shows "Develop needs a RAW file (jpeg)"; the histogram/masks/develop panels say "Open a RAW in the loupe (E)" (InspectorView.swift:200, HistogramView.swift:105, MasksPanel.swift:31, DevelopPanels.swift:644). On screen (tools/orchestrate/wp/M2-29v/verdict.json) a JPEG in the loupe never gets sliders.
1. Open a Develop session for every item kind the engine accepts (raw, jpeg, tiff, png, heic — check `PhotoItem.kind` cases and `EngineLibrary` for which kinds get an `engineImage`; PNG/HEIC/TIFF must be indexed and get a reference — verify with the scan, fix TesseraCore if they are skipped). Keep the synthetic-stub refusal.
2. Reword the empty-state hints to "Open a photo in the loupe (E)". Keep the "Develop needs…" message only for unsupported kinds.
3. Masks/AI masks on JPEG must work or be disabled with a clear hint if the engine refuses; check `MaskShared` behaviour on RGB sources and report.
4. Update ACCEPTANCE.md M2-29 section into numbered steps with identifiers; add a Swift test opening Develop on a generated JPEG through AppModel (or DevelopController) and a HEIC (generate via `sips -s format heic`).
5. Verify on screen yourself: build with `apps/mac/Support/make-app.sh`, launch on a `make-sample-folder.swift` shoot with `--app-dir`, open a JPEG in the loupe, press D, drag Exposure, screenshot the window (save under tools/orchestrate/wp/M2-43/evidence/), quit/relaunch and confirm persistence, export Full-size JPEG to a scratch folder and confirm the export is brighter (compare mean pixel via `sips` or a small swift script).
Gate: `(cd apps/mac && ./build-ffi.sh && swift build && swift test -c release -Xswiftc -enable-testing)`. Allowed: apps/mac/Sources/Tessera/**,apps/mac/Sources/TesseraCore/**,apps/mac/Tests/**,apps/mac/ACCEPTANCE.md,tools/orchestrate/wp/M2-43/**.
