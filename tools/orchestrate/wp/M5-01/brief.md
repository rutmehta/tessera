# WP M5-01 — Layer compositor core (Opus)

Read docs/02 §1 (document model: canvas, layers, smart objects, layer styles, channels/paths/selections, history), §2 (compositor and colour management: blend modes, Blend If, knockout, pass-through groups, 8/16/32-bit), docs/04 §2 and §4 (tiles, COW, per-layer mip caches, dirty-rect compositing), crates/engine-api (Tile, Pyramid, MemoKey, jobs), crates/image-core (cache, resident model), crates/pipeline-gpu (WGSL patterns), crates/color-mgmt.
Design and implement `crates/compositor` (currently a stub):
- **Document model**: `Document { canvas size, depth: U8|U16|F32, color profile, layers: tree }`, layer kinds: pixel (tiled COW raster with per-tile revision), adjustment (function of the composite below: levels/curves/HSL/etc. reusing pipeline-cpu operators where sensible), fill, group (pass-through or isolated), smart object (nested Document rendered and cached at parent resolution with a transform), text placeholder; per-layer: opacity, blend mode (all Photoshop modes incl. non-separable), Blend If per channel with split sliders, knockout shallow/deep, layer mask + vector mask placeholder, clipping mask, visibility, lock flags; selections as float single-channel tiled images.
- **Rendering**: scene-graph traversal producing tiles at any pyramid level; per-layer rendered-tile cache keyed by (layer id, revision, level, tile); invalidation propagates up the tree from the edited node; dirty-rect compositing for brush strokes (incremental); CPU reference implementation exact per the Photoshop blend formulas (document the maths in COMPOSITOR.md, including the non-separable modes and Blend If interpolation); GPU implementation in WGSL for the separable modes and the group/knockout pipeline, gated to the CPU reference (docs/11 §1.3).
- **History**: non-linear history of document ops (ops are the unit: add layer, paint stroke with tile deltas, set property) with snapshots; memory-bounded via COW tile sharing.
- **Serialization**: an internal `.tessera-doc` format (JSON manifest + tiled pixel chunks, zstd) round-tripping the whole model.
Tests: blend modes vs hand-computed references for 3 pixels each mode; group isolation vs pass-through; Blend If; knockout; adjustment layer stacking; COW: editing one tile of a duplicated layer does not touch the original; cache invalidation counts; GPU vs CPU tolerance; a 100-layer 20 MP synthetic document composites at level 2 in < 100 ms (bench, printed); round trip.
`cargo test -p compositor --release`, clippy -D warnings, fmt. engine-api unchanged (report needed fields).
