# WP M5-12 — Filters and direct adjustments in the app (Opus) — starts after M5-09 and M5-13 merge

Read docs/02 §7 (Image ▸ Adjustments), §8 (filters, Smart Filters), crates/filters (the `Filter` trait, params, GPU impls, halo), crates/tessera-ffi/src/document.rs (M5-09), apps/mac Document/* (M5-13), Inspector/DetailPreviewView.swift (the 1:1 detail preview pattern).
1. **FFI**: `preview_filter(layer, filter_json, region: Option<Rect>)` rendering the filter on the viewport level into the presented surface without a history node (cancellable, latest-wins), `apply_filter(layer, filter_json)` as one history node (destructive on pixel layers; on smart objects appended to the `SmartFilter` list with mask/opacity/blend), `set_smart_filter(layer, index, enabled|params|blend)`, `apply_adjustment(layer, adjustment_json)` for Image ▸ Adjustments direct ops, `list_filters() -> Vec<FilterInfo{id, group, name, params schema json}>` generated from the crate so the menu is data-driven.
2. **App**: Filter menu built from `list_filters` (groups: Blur, Sharpen, Noise, Distort, Stylize, Render, Other; Last Filter ⌃F), a filter sheet per filter with controls generated from the params schema (sliders, angles, choices, points) plus a live preview on the canvas and a 1:1 detail preview pane, "Preview" toggle, Reset, OK/Cancel; Image ▸ Adjustments ▸ (every `Adjustment` variant, reusing the M5-13 Properties editors inside a sheet, applied with `apply_adjustment`); Smart Filters shown under smart-object layers in the Layers panel (rows with enable toggle, double-click to re-edit, mask thumbnail, blend options sheet). Accessibility identifiers (`document.filter.<id>.*`), DESIGN.md compliance, ACCEPTANCE.md section: Gaussian blur preview/apply/undo on the DNG document, Levels via Image ▸ Adjustments, a smart filter toggled off and on.
Rust tests per FFI call (preview leaves history unchanged; apply adds one node; smart filter list round-trips through save/load). Swift tests: schema → control mapping, last-filter memory. `cargo test -p tessera-ffi -p filters --release`, clippy -D warnings, fmt, `(cd apps/mac && ./build-ffi.sh && swift build && swift test)`. engine-api unchanged. Allowed: Cargo.lock, crates/tessera-ffi/**, crates/filters/src/registry.rs (new file only, for `list_filters`), apps/mac/**, tools/orchestrate/wp/M5-12/**.
