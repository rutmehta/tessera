# Export integration

Export now uses the automatic CFA/DRUNet adapter with the cache-only application registry. It needs no host noise calibration and does not initiate model downloads. Supported native CFA recipes now prefer the resident GPU path through public Renderer/GpuStageOp APIs; depth/AI-mask combinations and unavailable or unsupported GPU capabilities fall back to the CPU reference hooks. The resident path runs at L0, yields to interactive work between tiles, retains cancellation, then performs reference area downsampling and output color management. GPU parity/cancellation tests skip only when the Metal device is unavailable.

Depth inference uses `DepthProvider` and its shared disk cache. The CPU reference renderer exposes `render_linear_before_geometry` and `render_linear_scaled_with_hooks`, keeping inference pixels aligned while applying denoise, optics, tone, and locals. The final depth-aware render applies blur before composed geometry and output downsampling. Model provenance must match pinned Depth Anything V2 Small when explicitly recorded. Disk depth hits remain usable without weights.

Only the exact exported `ml_depth::MISSING_MODEL_MESSAGE` becomes a Lens Blur skip warning. Corrupt weights, unsupported provenance, and inference errors fail the photo. Original recipe metadata retains the requested settings.

Warnings are available through `RenderedExport::warnings()` before encoding and `BatchReport::warnings()` after commit. Each nonempty report is stored beside the image as `<filename>.tessera-warnings.txt`. Publication refuses overwrites and rolls back its new warning/XMP files if image publication fails. The batch accessor returns warnings by successful input index and reports unreadable warning files as errors. Existing FFI/Swift batch consumers must opt into exposing this new report information; no consumer changes were made here.

AI-mask export receives the same denoise/depth hooks. Existing AI-mask lens-warp combinations remain explicitly unsupported rather than silently rendering misaligned masks.

Tests cover missing versus corrupt depth weights, pinned provenance, supplied depth before crop against the reference operator, cached depth reuse without weights, AI masks combined with depth, automatic RAW denoise reaching the disabled-download failure rather than demanding host calibration, persisted warning reports, and warning collision protection.

The original manifest's local CFA artifacts are also absent in this worktree at `tools/orchestrate/wp/M3-16/artifacts/cfa-{fp32,fp16}.onnx`. Explicit `ModelDownloads::open` callers can pass the original or correctly packaged manifest to preserve local path resolution and populate the shared cache. Automatic `from_support` registries are cache-only and never follow relocated local source paths.
