# WP M2-18 — Adobe Process Version 6 compatibility renderer (`pipeline-adobe`)

Goal (docs/05 §3.2, docs/07 §5 "Adobe PV6 compatibility mapper"): imported Lightroom edits (crs: keys, PV 15.4) render visually close to Lightroom so users trust the importer; new edits stay native. Read crates/engine-api (ProcessVersion::Adobe, DevelopSettings, crs table), crates/sidecar/src/develop.rs (crs→recipe mapping), crates/import-lrcat, crates/pipeline-cpu (native operators, OPERATORS.md), crates/color-mgmt.
Implement `crates/pipeline-adobe` as an alternative operator set selected when `ProcessVersion` is Adobe PV3–PV6 (image-core picks the op set by process version; add that switch, additive):
- Reverse-engineer from public knowledge only (Adobe's DNG SDK documentation for the camera profile pipeline: DCP HueSatMap/LookTable/ToneCurve application order and the "Adobe Standard" default tone curve; published analyses of ACR's Exposure/Contrast/Highlights/Shadows/Whites/Blacks behaviour; the well-known PV2012 tone curve shape; Lightroom's HSL and Vibrance behaviour). No Adobe code. Document every assumption in `ADOBE_COMPAT.md` with sources.
- Cover: DCP camera profile application (matrices by illuminant, HueSatMap, LookTable, ToneCurve) using the DCP parser (write one; DCP is a TIFF-like format, documented in the DNG spec), Exposure2012..Blacks2012 in ACR's order and domains, Clarity/Texture/Dehaze approximations, Vibrance/Saturation, HSL bands, ToneCurvePV2012 + per-channel, Split/Color grading, sharpening/NR params, vignette, grain, crop/angle. Unknown keys fall back to native.
- Fidelity harness: given a raw + its Lightroom-rendered JPEG (the embedded preview in a `.lrcat`'s Previews.lrdata, or a user-supplied export), compute ΔE2000 stats (mean/p95) between our compat render and the reference at 1/4 scale; `tessera-cli import lrcat --fidelity` prints it. Since no Lightroom samples exist on this machine, the tests use synthetic references: apply the native pipeline to produce a "reference" and assert the harness reports ~0 ΔE for identical inputs, and assert monotonic behaviours of each compat operator (Exposure +1 doubles linear midtones before the tone curve; Highlights −100 reduces the top decile without raising shadows; etc.).
`cargo test -p pipeline-adobe -p image-core -p tessera-cli --release`, clippy -D warnings, fmt. engine-api unchanged (report needed fields). Allowed: Cargo.lock, Cargo.toml, crates/pipeline-adobe/**, crates/image-core/src/backend.rs (op-set switch only, additive), apps/tessera-cli/**, tools/orchestrate/wp/M2-18/**.
