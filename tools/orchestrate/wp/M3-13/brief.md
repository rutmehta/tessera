# WP M3-13 — Keyword suggestions, captions, OCR (`ml-caption`)

Read docs/09 §1 (object/scene detection, OCR, auto keywords & captions), §3 (keywording: suggestions with confidence, bulk accept, mapping to the user's keyword tree), crates/ml-runtime (registry, session incl. token inputs), crates/ml-embed (SigLIP text tower: zero-shot labels), crates/library (keyword tree), crates/index (keyword tables, FTS), crates/sidecar (keyword write).
Licensing (docs/13): permissive weights only. Plan: (a) **zero-shot keywords** via SigLIP image/text similarity against a curated vocabulary (~2k photographic concepts: scenes, objects, activities, styles; ship the list as data; per-keyword confidence calibrated with a temperature); (b) **captions** with a permissive small VLM: **Florence-2-base** (MIT) or **SmolVLM-256M** (Apache-2.0) exported to ONNX (document export; pin hashes; no weights committed), producing a one-sentence caption and alt text; (c) **OCR**: Florence-2's OCR task if used, else **PaddleOCR** ONNX (Apache-2.0) detection+recognition; text stored in the index FTS so "search inside images" works; (d) hierarchical mapping: suggested keywords mapped onto the user's keyword tree by name/synonym match, else proposed under a "Suggested" node.
Implement `crates/ml-caption`: `suggest_keywords(image) -> Vec<(keyword, confidence)>`, `caption(image) -> {caption, alt_text}`, `ocr(image) -> Vec<{text, bbox, confidence}>`, a background job at Priority::Score with batching, index writers (opt-in XMP write per docs/09), and `tessera ml keywords|caption|ocr <image>` CLI.
Tests: zero-shot on synthetic images (a red disc → "circle"/"red" rank in the top-5 of a small vocabulary); mapping tests against a synthetic keyword tree with synonyms; OCR on a rendered text image (draw text with a bundled font via `ab_glyph`/`fontdue`, permissive) recovers the string when the model is cached (skip offline); caption integration on the fixtures when cached; CoreML partition report.
`cargo test -p ml-caption -p index -p tessera-cli --release`, clippy -D warnings, fmt. engine-api unchanged. Allowed: Cargo.lock, Cargo.toml, crates/ml-caption/**, crates/ml-runtime/models.toml, crates/index/**, crates/library/**, apps/tessera-cli/**, tools/**, tools/orchestrate/wp/M3-13/**.
