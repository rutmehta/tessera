# WP B5-11b — Shapes/Pen and document-mode fixes from the on-screen verification of B5-11 (Opus, Machine B)

Base: origin/main at cf9dc6f (contains B5-10, B5-10b, B5-10c, B5-11 and M5-34 if merged). Read tools/orchestrate/wp/B5-11b/VERIFY-REPORT.md (the verifier's on-screen report for B5-11; items 11–13 come from its B5-10c re-check), tools/orchestrate/wp/B5-11/IMPLEMENTATION-STATUS.md, and the code under apps/mac/Sources/{Tessera,TesseraCore}/Document/Vector/**, Document/Tools/**, App/KeyRouter.swift, PropertiesPanel.swift, crates/tessera-ffi/src/document/vector.rs.
Fix, each with a test that fails first:
1. **A twice** stays on Path Selection; the spec says pressing A again (or ⇧A) switches to Direct Selection. Make A cycle Path ↔ Direct like ⇧U cycles shapes.
2. **Stroke takes the fill colour** when enabled on an existing shape, so dashes are invisible. Default a newly enabled stroke to the foreground colour when it differs from the fill, otherwise a contrasting default (black/white by fill luminance).
3. **Keyboard steps on the dash-offset slider made 3 Edit Shape rows** in one adjustment. Coalesce keyboard-driven slider steps into one history node (commit on key-up after a short idle, like drags), for all shape inspector sliders.
4. **Pen draft hides earlier direction handles** after the next point is placed. Keep the previous anchor's handles visible in the draft (Photoshop shows the last segment's handles).
5. **Vector mask thumbnail missing** in the Layers row (only the raster mask shows). Show a separate vector-mask thumbnail when a layer has a vector mask.
6. **Locked-layer recolour leaves the colour well showing the rejected colour** until reselection. Revert the well to the model value when the engine rejects the edit.
7. **Tool shortcuts ignored while a Properties slider or the Layers list has keyboard focus** (U, ⇧U, Z …). In document mode, single-key tool shortcuts must work unless a text field (or the Type tool's input) is editing; sliders and outline views should not swallow them. Add a KeyRouter test.
8. **Path Selection: click on empty canvas does not deselect.** Make it deselect the path/shape selection.
9. **Stale status hints** ("Pen path discarded" after Return created a shape; the Remove hint persists after switching to Move). Generalise B5-10c's approach: each tool's hint is derived from current tool/session state and refreshed on every tool/session change.
10. **Properties shows Position 0,0 / Bounds "Whole canvas" for new shapes.** Report the shape's real bounds (from the engine's shape bounds / transform) and update them live during drags.
11. **New area text resized before the first apply** records "Typing" + "Edit Text" instead of one "Add Text" (+ "Resize Text Box"): the box resize flushes the draft as a "Typing" node. A new layer's first apply must be "Add Text", with the resize folded in or recorded after it.
12. **Idle Type hint after applying area text** still reads "Area text: …" until the next draft starts; it should return to the tool's idle hint.
13. **Text layer name does not follow its content** ("Hi" stays after editing to "HiZQ…"). Like Photoshop, an auto-named text layer's name follows its first line of text until the user renames it; a user rename sticks.
(The step-379 FX question was resolved on screen as a verifier misclick, not a bug.)
