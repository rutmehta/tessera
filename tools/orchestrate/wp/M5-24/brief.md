# WP M5-24 — Auto-Align Layers, Auto-Blend Layers (panorama seams + focus stack), Photomerge into the document

Read docs/02 §6 (Auto-Align, Auto-Blend, Photomerge) and its implementation notes, crates/merge (pano.rs feature matching/RANSAC/cylindrical/spherical, blend.rs seam finding + multiband, HDR deghost), crates/compositor (document.rs layers/masks, edit.rs DocOp, COMPOSITOR.md), crates/transform (affine/homography ops added by M5-21, TRANSFORM.md).
Deliver in crates/merge (new module `layers.rs` or similar) + compositor DocOps:
1. **Auto-Align Layers**: given N document layers, estimate per-layer alignment (Auto / Perspective / Cylindrical / Spherical / Collage / Reposition-only; optional vignette + geometric distortion removal) using the existing merge feature pipeline; output is a per-layer `TransformOp` (from crates/transform) applied non-destructively via the compositor's transform stage, plus the canvas extended to the union bounds. Deterministic with a seed.
2. **Auto-Blend Layers**: Panorama mode → graph-cut seam masks per layer (reuse blend.rs) written as layer masks plus optional "seamless tones and colors" (multiband correction) as a per-layer adjustment; Stack mode → Laplacian-pyramid focus measure selection producing masks per layer; "content-aware fill transparent areas" option calls `filters::caf` on the union hole.
3. **Photomerge**: one call = open files as layers (RGB rasters supplied by the caller) → Auto-Align → Auto-Blend, options as in Photoshop's dialog; result is an undoable history group.
Tests: synthetic panorama of 3 shifted/rotated crops of a textured image → aligned within 0.5 px RMS and seams invisible (seam error metric); synthetic focus stack (3 differently blurred regions) → each region's sharpest source selected ≥95% of pixels; determinism; PSD export of the result keeps masks (rasterised transforms). Bench: 3 × 24 MP align+blend under 6 s CPU (ignored test, log numbers).
