# WP B5-10c — Type tool fixes from the on-screen verification of B5-10 (Opus, Machine B)

Base: wp/B5-11 (contains B5-10, B5-10b and B5-11 on main 571630c). Keep shape/vector behaviour intact.

Read tools/orchestrate/wp/B5-10c/VERIFY-REPORT.md (the verifier's on-screen report for B5-10; copy placed next to this brief), tools/orchestrate/wp/B5-10/IMPLEMENTATION-STATUS.md, and the Type tool code under apps/mac/Sources/Tessera/Document/Text/** and TesseraCore/Document/Text/**, plus crates/tessera-ffi/src/document/text.rs.
Fix, each with a test that fails first:
1. **⌘Return stops applying after a text-box handle drag** (step 347; reproduced twice). Keypad Enter and the Apply button still work. Likely the first responder leaves the text input view after the handle drag: restore it on mouse-up, and make ⌘Return / Enter / Esc route to the active text session regardless of which view in the document window is first responder while a text draft exists.
2. **A click just right of the last glyph starts a new text layer** instead of resuming editing: hit-test existing text layers with their line box plus a small trailing margin (document the value), preferring resume over create.
3. **Stale status hint**: "Area text:" shown while editing point text and "Type: cancelled" shown during a new edit; derive the hint from the current session state on every change.
4. **Latency readout** reported p95 76,844 ms after 10 keys on a 1200×800 document: it probably measures until a frame is presented to an inactive window. Measure keystroke → frame completed by the renderer (FrameInfo), exclude time the window was not visible/active, and label the readout accordingly.
5. **Area-text box outline** is solid; the spec says dashed. Make it dashed per DESIGN.md.
6. Selection highlight extends ~5 px (retina) past the ink on both sides because it uses the advance box: keep advance-box semantics (it matches Photoshop), but document it in DESIGN.md so verifiers do not flag it.
Out of scope (reported to Machine A): toolbar overlapping the options bar/inspector, content under the title bar after resize, --app-dir folder registry leak.
Background-only on this Mac: launch with `open -g -n`, drive with the text self-test argument (extend it for items 1–3), no activation or System Events input, screenshots only via `screencapture -x -o -l <windowID>` of your own window, quit only your PID.
Gate (from the worktree root): `export CARGO_TARGET_DIR="$HOME/.cache/tessera-target/B5-10c" MACOSX_DEPLOYMENT_TARGET=15.0 CARGO_BUILD_JOBS=2`; `cargo test --locked --release -p tessera-ffi`; `cargo clippy --locked --release -p tessera-ffi --all-targets -- -D warnings`; `cargo fmt --all -- --check`; `(cd apps/mac && ./build-ffi.sh && swift build --jobs 2 && swift test --jobs 2)`; `(cd apps/mac && xcodebuild -scheme Tessera -configuration Debug -destination 'platform=macOS' -derivedDataPath "$HOME/.cache/tessera-derived-data-B5-10c" -jobs 2 build)`.
