# WP M5-22 — Liquify, content-aware fill / move, and the inpainting hook

Read docs/02 §5 (Retouching: Liquify, Spot Healing/Content-Aware, Content-Aware Move, Remove) and §3, crates/brush (heal.rs PatchMatch-based `patch` + `poisson_blend`, engine.rs stroke/dab model, gpu.rs), crates/filters (how filters provide CPU + Metal evaluation and plug into the smart-filter stack via compositor_adapter.rs), crates/ml-faces (landmarks5), crates/ml-runtime (model registry / models.toml conventions), crates/selection.
Deliver in `crates/filters` (or a new `crates/liquify` if cleaner — your call, document it):
1. **Liquify**: a displacement mesh (vector field at configurable cell size) edited by brushes: forward warp, reconstruct (revert/amount), smooth, twirl CW/CCW, pucker, bloat, push left, with freeze/thaw mask, brush size/density/pressure/rate; render by inverse mapping with bilinear/bicubic; mesh save/load (serde, versioned); non-destructive as a smart filter stage. **Face-Aware Liquify**: from the 5 YuNet landmarks derive parametric warps (eye size/height/width/tilt, nose width/height, mouth smile/width/height, face width/jaw/chin/forehead) per detected face, applied to the mesh; tests with synthetic landmark sets. GPU port of the render via displacement texture (bit-exact vs CPU ≤ 1e-4).
2. **Content-aware fill** (`filters::caf` or in brush::heal): PatchMatch with sampling area (auto/rectangular/custom), colour adaptation (none/default/high/very high), rotation adaptation, scale/mirror options, output to new layer; **Content-Aware Move / Extend** = cut-paste + fill + seam gradient blending. Quality tests: fill a hole in a synthetic texture and assert boundary seam error and texture statistics.
3. **Inpainting hook**: a `Remove` trait with a CPU PatchMatch implementation and an `ml-enhance`-style ONNX slot (LaMa-class model is Apache-2.0 "big-lama" — do NOT download; add the registry entry with a TODO hash and a test that the loader reports missing weights cleanly).
Wire the new filters into the compositor smart-filter stack enum so documents round-trip (native format only; PSD degrades to rasterised with a note). Bench: Liquify 24 MP render CPU < 300 ms, GPU < 25 ms; CAF 512×512 hole in 24 MP < 2 s. Gate: `cargo test -p filters -p brush -p compositor --release && cargo clippy -p filters -p brush -p compositor --all-targets -- -D warnings && cargo fmt --check`. Allowed: Cargo.toml,Cargo.lock,crates/filters/**,crates/brush/**,crates/liquify/**,crates/compositor/src/edit.rs,crates/compositor/src/format.rs,crates/compositor/src/document.rs,crates/compositor/tests/**,crates/ml-runtime/models.toml,tools/orchestrate/wp/M5-22/**.
