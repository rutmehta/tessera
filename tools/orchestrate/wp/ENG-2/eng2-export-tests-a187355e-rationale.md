# ENG-2 Export Flat test patch rationale

The patch adds two `document_export_flat.rs` integration cases using the existing deterministic noise-layer fixture, synchronous PNG exports as pixel oracles, and the existing `png_pixels` comparator. The first starts a job at confirmation, commits a visibility edit afterward, proves the later state differs, and requires the job to match the earlier pixels. The second reads the chosen layer and its baseline opacity from the returned layer record, verifies the interactive value is visible while the history head is unchanged, then captures that scratch state. It returns the gesture to the observed baseline, commits it, applies a different committed visibility change, and proves the job still matches the scratch oracle rather than the later state.

Both cases assert output contrasts so a no-op/vacuous test cannot pass. This tests snapshot compatibility against the frozen API; it is not a RED test for ENG-2 lock independence. Source basis: `document.rs:1547–1561` documents immediate visibility edits and interactive opacity; `document.rs:1839–1852` commits pending edits; `document.rs:2214–2235` snapshots `st.live()` in `begin_export_flat`; existing fixture/oracle patterns are in `document_export_flat.rs:36–77, 205–235`. Not applied or executed.
