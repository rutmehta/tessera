# WP M3-09 — Style profile auto-edit ("edit like me"), agentic phase 1 (`style-profile`)

Read docs/10 §2 (style profile), §3 phase 1, docs/09 §2 ("Style profiles"), crates/cull-learn or the learner inside crates/cull (M3-07: feature vectors, PCA, online learner, persistence pattern), crates/ml-embed (image embeddings), crates/ml-quality, crates/ml-faces, crates/index (recipe_hash, history), crates/sidecar (recipes), engine-api DevelopSettings (which fields are "base edit": WB, Basic tone, presence, HSL/grading amounts, crop is excluded), crates/pipeline-cpu (render for the critic metrics), crates/tessera-mcp (Console for applying tools with Author::Agent).
Implement `crates/style-profile`:
- **Training data**: from a library, collect (features → final DevelopSettings deltas from defaults) for every image the user has edited (history non-empty, Author::User); features = SigLIP embedding (PCA 64), scene stats (histogram percentiles, mean luminance, clipping fractions, WB as-shot CCT/Duv), faces aggregate, camera/lens ids. Persist the profile per library (JSON + weights) with versioning.
- **Model**: ridge/kernel regression per output slider (pure Rust, no heavy deps) with per-slider confidence; cold start via a questionnaire struct (brightness preference, contrast, warmth, saturation, skin-tone priority) mapped to priors, plus optional "reference edits" (a handful of before/after recipes) that seed the training set.
- **Predict**: `predict(image) -> (DevelopSettings base, per-slider confidence, rationale strings like "lifted shadows +25 because faces measured 1.3 EV under mid-grey")`.
- **Batch apply**: job at Priority::Score over a shoot with consistency constraints (same burst group → same WB/tone; same person id → same skin/exposure treatment), writing the prediction as one history group named "Agent base edit" with `Author::Agent` through the MCP Console (or directly via Recipe::edit with the same metadata), with a single amount fader semantics stored in the group (the UI fades the group later); produces a review queue sorted by low confidence first.
- **Feedback**: accepted/changed steps update the training set (online); expose `record_feedback(image, final_settings)`.
- Tests: synthetic library where the "user style" is a fixed linear function of scene mean luminance + embedding → after 40 training examples, prediction error on 50 held-out < 10% of slider range; consistency constraint test (burst shares WB); history group has Author::Agent and rationale; cold-start priors produce the questionnaire's direction; persistence round trip.
`cargo test -p style-profile --release`, clippy -D warnings, fmt. engine-api unchanged (report needed fields, e.g. a group "amount" if missing).
