# WP M5-05 — Brush engine and selection tools (Opus)

Read docs/02 §3 (selection & masking tools: marquee, lasso, magic wand, quick selection, object/subject/sky select, select & mask refinement, colour range, focus area), §4 (painting: brush engine with tip shapes, dynamics, dual brush, texture, wet edges, airbrush, smoothing, symmetry; ABR import; clone/heal/patch basics), §5 (retouching), crates/compositor (Raster public API, selections as float single-channel rasters; M5-04b is editing gpu.rs/render/* concurrently: depend only on published Raster/Document APIs and put new code in new crates), crates/filters (blur/refinement utilities), crates/ml-segment (subject/sky/promptable), crates/pipeline-cpu masks (brush stamping from M2-08 for reuse ideas), engine-api 1.2 document tools (`paint_stroke`, `set_pixel_selection`).
Implement two crates:
- `crates/brush`: stroke model (points with pressure/tilt/velocity, smoothing/stabiliser, spacing by tip size), tip shapes (round hardness, sampled tips from ABR: parse ABR v6/v10 with permissive code, no GPL), dynamics (size/opacity/flow/angle/scatter jitter by pressure/velocity/random), dual brush and texture, wet edges, airbrush accumulation, symmetry (mirror/radial), blend into a target Raster with all blend modes via the compositor's blend functions, incremental dab rendering returning the dirty rect; eraser and clone source offset; heal (Poisson-blend seamless clone on the dab area; use a simple iterative solver) and patch basics. GPU dab rendering in WGSL for round/sampled tips, gated vs CPU.
- `crates/selection`: marquee (rect/ellipse, feather, anti-alias), lasso (free/polygonal/magnetic via edge cost), magic wand (tolerance, contiguous), quick selection (region growing seeded by strokes with colour/texture similarity), colour range (fuzziness), focus area (sharpness map), object/subject/sky via ml-segment, boolean ops, transform selection, refine edge (radius, smart radius via guided filter, smooth/feather/contrast/shift), decontaminate colours placeholder, marching-ants outline extraction (contour tracing to polylines for the UI), save/load as alpha channels.
Tests: dab placement/spacing maths; dynamics determinism with a seed; ABR round trip on a synthetic file; stroke on a Raster matches a scalar reference; GPU dab vs CPU tolerance; heal on a synthetic gradient leaves no seam (max second derivative bound); each selection tool on synthetic images selects the expected region (IoU > 0.95); boolean ops; refine edge preserves a hard edge; contour tracing yields closed polylines for a disc.
`cargo test -p brush -p selection --release`, clippy -D warnings, fmt. engine-api unchanged. Allowed: Cargo.lock, Cargo.toml, crates/brush/**, crates/selection/**, tools/orchestrate/wp/M5-05/**.
