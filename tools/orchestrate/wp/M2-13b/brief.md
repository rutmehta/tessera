# WP M2-13b — Lightroom Classic import in the app (Opus)

Read docs/05 §3 (import UX and fidelity report), docs/06 §2.1 (selection mapping preview), crates/import-lrcat (ImportPlan, inspect, apply, library writer, FINDINGS), crates/library, crates/tessera-ffi (Engine, LibraryStore), apps/mac (Sidebar, menus, sheets from M2-12).
1. FFI: `inspect_lrcat(path) -> Summary` (counts: folders, images, virtual copies, keywords, collections, smart collections, unsupported items with reasons, disk-space estimate, whether Lightroom is running / catalog locked), `plan_lrcat(path, options) -> PlanPreview` (per-folder mapping table, selection mapping preview counts: how many become Reject/Keep/grades/marks, mark-name mapping editable, root folder relocation for moved drives), `apply_lrcat(plan, progress callback, cancel)` writing sidecars + library.json + index via the existing crates, resumable; `fidelity_sample(plan, n)` renders n imported images through the compat renderer when `crates/pipeline-adobe` exists on main (feature-detect; otherwise native) and compares against the catalog's preview JPEGs from `Previews.lrdata` (read the pyramid format: it is a simple container of JPEG levels; document) returning ΔE2000 mean/p95 per image and thumbnails of both.
2. App: **File ▸ Import Lightroom Catalog…** sheet with steps: choose `.lrcat` → summary → mapping (folders with relocation, selection mapping table with editable mark names, keyword hierarchy preview) → fidelity preview (grid of before/after pairs with ΔE badges, sortable, "looks different" filter) → import with progress and a final report (what was imported, what was skipped and why) saved as `import-report.md` next to library.json. Non-modal progress; cancellable; safe by construction (never writes into the catalog).
3. ACCEPTANCE.md section: uses the synthetic `.lrcat` fixture from crates/import-lrcat tests (expose a `tessera-cli import lrcat --make-fixture <dir>` if needed, allowed) to walk the sheet end to end.
Tests: Rust for the FFI surface with the synthetic catalog; Swift tests for the mapping table model and report rendering. `cargo test -p tessera-ffi -p import-lrcat --release`, clippy, fmt, `(cd apps/mac && ./build-ffi.sh && swift build && swift test)`. engine-api unchanged.
