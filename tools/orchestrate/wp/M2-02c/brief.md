# WP M2-02c — Importer: map Lightroom star ratings in smart-collection rules to grades

Bug found by M2-13b: `crates/import-lrcat` copies Lightroom star values verbatim into `SavedSearch` rules, but Tessera's `rating` term means grade 0–3 (docs/06 §2.1: 1★→Keep (grade none), 2★→1, 3–4★→2, 5★→3, and Reject is decision:reject). So "rating >= 3" (three stars) currently becomes grade 3 (five-star only). Fix the rule translation for all comparison operators (`>=`, `>`, `=`, `<=`, `<`, ranges) so the imported rule selects the same set of images as Lightroom would over the mapped selection; `rating = 0` / "unrated" maps to decision:undecided; `pick`/`reject` flags map to decision terms. Add table-driven tests over all star thresholds and operators using the synthetic catalog fixture (compare the rule's matches against the mapped selections of the fixture's images). Update FINDINGS/README.
`cargo test -p import-lrcat -p library --release`, clippy -D warnings, fmt. Allowed: crates/import-lrcat/**, crates/library/** (only if the grammar needs a helper), tools/orchestrate/wp/M2-02c/**.
