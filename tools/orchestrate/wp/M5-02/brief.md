# WP M5-02 — PSD/PSB read and write (`psd`)

Read docs/02 §1.7 (file formats: PSD/PSB with layers, masks, adjustment layers, smart objects, text, styles, channels, paths), Adobe's public Photoshop File Format specification (fetch it; it is documented), crates/compositor (M5-01 is designing the Document model concurrently: code against the model described in tools/orchestrate/wp/M5-01/brief.md, using a local `PsdDocument` intermediate representation so this crate compiles standalone; a thin adapter to `compositor::Document` is added when M5-01 lands).
Implement `crates/psd` (permissive deps only; do not use GPL crates): header/colour mode/depth (8/16/32), image resources (ICC profile, resolution, layer selection, slices ignored), layer and mask info (layer records, channel data with RLE/ZIP/raw, blend modes, opacity, clipping, flags, masks, Blend If ranges), additional layer info keys: `lsct` (groups), `luni` (names), `lyid`, `lfx2`/`lrFX` (styles preserved as opaque + parsed drop shadow/stroke/outer glow basics), `SoCo`/`GdFl`/`PtFl` (fills), adjustment layers (`levl`, `curv`, `brit`, `hue2`, `blnc`, `expA`, `vibA`, `phfl`, `blwh`, `mixr`, `selc`, `thrs`, `post`, `nvrt`), `SoLd`/`PlLd` + `lnkD` (smart objects with embedded originals), `TySh` (text: preserve engine data opaque, extract string/font/size), `vmsk`/`vsms` (vector masks as path records), `Patt`; composite (merged image) read/write; PSB (large document) variant; write-back that preserves unknown keys opaquely (round-trip fidelity).
Tests: synthesise PSDs in-test via the writer and read them back (round trip for every supported key); parse hand-built minimal PSD bytes for each compression; property tests on RLE; a PSB with > 30000 px dimension; and, if any real PSD sample under a permissive licence is available (e.g. from the `psd` crate's test assets if MIT — check), an integration test. Fuzz-ish robustness: truncated files return errors, never panic.
`cargo test -p psd --release`, clippy -D warnings, fmt. engine-api unchanged. Allowed: Cargo.lock, Cargo.toml, crates/psd/**, tools/orchestrate/wp/M5-02/**.
