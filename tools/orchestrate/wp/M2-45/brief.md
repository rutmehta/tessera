# WP M2-45 — Export completeness: AVIF, JPEG XL, DNG, watermark, size limit, HDR output, post-processing

Read docs/01 §(Export, line ~360: the full Lightroom export dialog feature list), docs/13-licensing.md (allowed licences; `jpegxl-rs` is GPL → banned; libjxl itself is BSD-3), crates/export (codec.rs, batch.rs, filter.rs, gpu.rs, lib.rs; ExportSettings and where it is defined — grep `pub struct ExportSettings`), crates/tessera-ffi/src/export.rs, apps/tessera-cli/src/export.rs, crates/merge (float DNG writer — reuse for DNG export), crates/color-mgmt (ICC embedding, Rec.2020/P3), crates/pipeline-gpu/src/export_resize.rs (output sharpening hook), crates/sidecar (metadata).
Add to the export engine, with settings fields (serde, backward compatible), CLI flags and FFI records so the app dialog can expose them later:
1. **AVIF** encode (ravif/rav1e, BSD; 8/10/12-bit, quality, speed, ICC/CICP tagging, alpha) and **JPEG XL**: lossless via `zune-jpegxl` (MIT/Apache); lossy via a vendored **libjxl** (BSD-3) FFI crate `crates/libjxl-ffi` built statically like libraw-ffi if the build is clean on macOS within this package (cmake/brotli/highway deps bundled); otherwise implement lossless only and document precisely why. Decoding of both for import/develop is out of scope here.
2. **DNG export**: linear DNG (demosaiced, float or 16-bit) from a developed raw with the recipe baked or as "original + XMP" copy; lossy DNG optional; embed original toggle; DNG 1.6 tags; validate with a round-trip decode through libraw-ffi.
3. **Watermark**: text (font, size relative to short edge, colour, opacity, anchor 3×3, inset, rotation) and graphic (PNG with alpha, scale, opacity, anchor, inset) rendered after resize/sharpen; deterministic tests.
4. **Limit file size** for JPEG (binary search on quality, ≥ N iterations bound) and **output sharpening** (screen/matte/glossy × low/std/high) if not already wired; **metadata policy** (all / copyright / copyright+contact / all except camera; remove person info; remove location; keywords as hierarchy) applied to XMP/EXIF output.
5. **HDR output**: 16-bit PNG/AVIF/JXL PQ or HLG with Rec.2020 tagging, and an **ISO 21496-1 / Adobe gain-map JPEG** (base SDR + gain map + metadata) from the HDR render; tests validate tags and that the reconstructed HDR matches within tolerance.
6. **Post-processing actions**: after-export hooks (reveal in Finder, open with app path, run a script) as a struct the host executes; **Export with Previous** = persisted last settings; **multiple presets in one export** = a list of settings run over the same selection.
Tests for every codec/setting (round trips, ICC, orientation, size limit convergence, watermark placement, HDR tags), CLI `tessera export --help` lists the new flags, FFI export records extended (regenerate bindings; keep the Swift app compiling — do not add UI).
