# Closed captured CFA adapter — independent plan review

Read-only review against main capture/RawSource/libraw-ffi implementations and /tmp/tessera-raw-capture-decoder-next-plan.md. No codec edits, tests, builds or decoder execution. No architectural blocker identified in the bounded owned-CFA-u16 approach. Implementation approval still depends on RED/GREEN and concrete source review.

## Clarifications to make before implementing

1. **Make the classifier-to-native cancellation boundary explicit.** Task1 currently says check entry, classify, then construct RawSource, and only explicitly checks again after open. Add a check after classification and immediately before native open, so cancellation observed during classifier I/O prevents a potentially long native open. Retain a final check after all owned metadata/consistency work before publication; describe cancellation during cleanup honestly (no atomic cancellation/publication guarantee). Define and test which result wins when cancellation and classifier/native failure occur at the same boundary; existing capture checks cancellation before propagating I/O results. Never accidentally bypass common cleanup/secondary-error reporting with a top-level `?`.

2. **Keep actual and synthetic lifetime evidence distinct.** A fake decoder-drop event proves the protocol, not RawFile destruction. Production should have an explicit inner scope/owned tuple: classifier borrow ends; RawSource opens/unpacks/copies metadata; native owner drops; only then stage.close. RawFile::open already closes a partially constructed native handle on open failure (libraw-ffi/src/lib.rs:75–78). RawFile::Drop closes the successful handle (196–199). Verify this real path by source and an actual-fixture test whose removal hook is reached only after that scope; do not claim fake lifecycle instrumentation observes libraw_close itself. Panic unwinding coverage does not cover abort/OOM/process termination.

3. **Require positive fixture inventory in the qualification command.** Existing raw-decode fixture_tests::fixtures_decode returns successfully when its root is missing. Do not inherit that as acceptance of the new adapter. The new representative gate must emit/validate executed family names and distinguish missing Sony/Fuji/Nikon/Canon/CFA-DNG inputs from passing families. Exact CFA and all metadata comparison against direct RawSource is appropriate; ordinary `PartialEq` floats would mishandle NaNs/signed zero, so use bit comparisons as planned. Record input/output checksums and original-fixture before/after hashes.

4. **Correct “case-preserved stored suffix.”** Capture normalizes with to_ascii_lowercase (capture.rs:280 onward), and pinned route describes a normalized suffix. The new test should prove upper-case input ARW becomes stored `.arw`, retained independently of a replaced/renamed original `.bin`; it must not expect case preservation.

## Confirmed sound boundaries

- CapturedRaw owns sealed stage and pool reservation and does not retain the source locator. Keeping self alive across a RawSource inner scope provides the necessary private pathname lifetime without returning paths/readers/native owners.
- Classifier can safely use the existing readonly descriptor even though capture hashing leaves it at EOF: is_linear_dng seeks to end then absolute offsets. It is a bounded classic-TIFF first-IFD classifier, not exhaustive LinearRaw recognition. Only a recognized positive is guaranteed Unsupported before LibRaw; malformed classifier errors should become Decode without fallback. Formats outside classifier recognition still go through LibRaw CFA validation. Preserve this narrow wording.
- RawSource.decode_cfa_u16 calls native unpack and then copies samples before returning; there is no cancellation opportunity between those operations without a wrapper/API change. Metadata reads after unpack are owned strings/arrays/opcode Vecs. Comparing full sensor width, height and CfaLayout is correct; do not compare against oriented/cropped dimensions or silently apply orientation/crop.
- CfaU16 validation already rejects zero/missing/malformed CFA planes and Unsupported layouts. The proposed adapter preserves integer samples/calibration verbatim and does not establish rendering suitability. Memory/time caps on native decode are explicitly absent; capture byte quotas and post-copy checks cannot be represented as those caps.
- Existing StageGuard closes the readonly descriptor before unlink, quarantines failed unlinks while retaining the quota charge, and pool destruction performs its bounded final retry. The adapter must preserve primary decode/cancel errors and report secondary cleanup errors; otherwise-successful output is discarded on cleanup failure. No output should escape before that finish policy completes.
- Identity should be copied from the verified CapturedRaw, not recomputed from original paths or inferred from dimensions. Real fixture A→invalid B locator replacement tests provide meaningful evidence. This still names captured bytes, not an atomic external source snapshot, renderer recipe identity or cross-version pixel reproducibility.

Recommended disposition: proceed with tests/scaffold after incorporating the small cancellation/fixture/suffix clarifications; retain the planned narrow production surface and defer broader render/dependency/memory guarantees.
